# Configuration reference

All settings are environment variables, read in `mvault_project/settings.py`. Any variable read through that file also accepts a `NAME_FILE` form that points to a file containing the value (for example a Docker secret: `MVAULT_ENCRYPTION_KEY_FILE=/run/secrets/mvault_key`). The file wins over `NAME`; trailing whitespace is stripped.

In the all-in-one image the generated secrets are also written to `/data/config/secrets.env`; see [Installation](installation.md#1-docker-all-in-one). For local development, `.env.local` next to `manage.py` is loaded automatically (never in containers).

Legend – **Req**: ● required, ◐ required in some modes (see description), ○ optional.

## Core

| Variable | Default | Req | Description |
|---|---|---|---|
| `MVAULT_BASE_URL` | *(empty)* | ● | Public URL, e.g. `https://vault.example.com`. Adds the host to allowed hosts and the origin to CSRF-trusted origins; if `https`, secure cookies and HSTS default **on**. Without it only `localhost`/`127.0.0.1` are allowed (the all-in-one image falls back to accepting any host, with a warning). |
| `DJANGO_SECRET_KEY` | – | ◐ | Django signing key (`openssl rand -hex 48`). Required unless `DJANGO_DEBUG` is on. The all-in-one image generates and persists one. Changing it signs everyone out. |
| `DJANGO_ALLOWED_HOSTS` | *(empty)* | ○ | Extra comma-separated host names (in addition to `MVAULT_BASE_URL`, `localhost`, `127.0.0.1`). |
| `DJANGO_CSRF_TRUSTED_ORIGINS` | *(empty)* | ○ | Extra comma-separated origins, e.g. `https://vault.example.com`. |
| `DJANGO_DEBUG` | `false` | ○ | Development only. Never enable in production. |
| `MVAULT_TIME_ZONE` / `TZ` | `UTC` | ○ | Time zone for display (`MVAULT_TIME_ZONE` wins over `TZ`). |
| `SESSION_COOKIE_SECURE` | `true` if `MVAULT_BASE_URL` is https, else `false` | ○ | Mark session and CSRF cookies `Secure`. Over plain HTTP set it `false`, or sign-in cannot work. |
| `MVAULT_HSTS_SECONDS` | `31536000` if `MVAULT_BASE_URL` is https, else `0` | ○ | `Strict-Transport-Security` max-age. Set `0` to disable. |

## Encryption

| Variable | Default | Req | Description |
|---|---|---|---|
| `MVAULT_ENCRYPTION_KEY` | – | ◐ | Master secret (`openssl rand -hex 32`). The AES-256-GCM key is derived from key + salt with scrypt. Required outside `DJANGO_DEBUG`/tests. Generated by the all-in-one image only with an embedded database (or `MVAULT_AUTO_GENERATE_SECRETS=true`). **Back it up.** |
| `MVAULT_ENCRYPTION_SALT` | – | ◐ | Salt for the derivation (`openssl rand -hex 32`). Same rules as the key. |
| `OLD_MVAULT_ENCRYPTION_KEY`, `OLD_MVAULT_ENCRYPTION_SALT` | – | ○ | Only for `manage.py rotate_encryption_key`: the values currently in use, while `MVAULT_ENCRYPTION_*` hold the new ones. Not read by `settings.py` (no `_FILE` form). |

## Database

Use `DATABASE_URL` **or** the `DB_*` variables (`DATABASE_URL` wins). PostgreSQL 14 or newer.

| Variable | Default | Req | Description |
|---|---|---|---|
| `DATABASE_URL` | – | ◐ | `postgres://user:pass@host:5432/name` (percent-encode special characters in the password). |
| `DB_HOST` | `localhost` | ◐ | Host. |
| `DB_PORT` | `5432` | ○ | Port. |
| `DB_NAME` | `mvault` | ○ | Database name. |
| `DB_USER` | `mvault` | ○ | Role. |
| `DB_PASSWORD` | *(empty)* | ◐ | Role password. |
| `DB_ENGINE` | `django.db.backends.postgresql` | ○ | Advanced; mVault is built and tested for PostgreSQL. |

## Object storage (optional)

Leave `S3_ENDPOINT_URL` empty to run without storage; icons, avatars and file records are then unavailable.

| Variable | Default | Req | Description |
|---|---|---|---|
| `S3_ENDPOINT_URL` | – | ○ | Endpoint, e.g. `http://minio:9000`. |
| `S3_ACCESS_KEY`, `S3_SECRET_KEY` | – | ◐ | Credentials. Storage counts as configured only when endpoint **and** both keys are set. |
| `S3_REGION` | `us-east-1` | ○ | Region sent to the S3 API (MinIO ignores it). |
| `S3_ICONS_BUCKET` | `mvault-icons` | ○ | Bucket for project/folder icons. |
| `S3_AVATARS_BUCKET` | `mvault-avatars` | ○ | Bucket for avatars. |
| `S3_ATTACHMENTS_BUCKET` | `mvault-attachments` | ○ | Bucket for file records (keep private). |
| `ICONS_PUBLIC_BASE_URL` | *(empty)* | ○ | If set, icon `<img>` tags point to this base URL (for a public bucket) instead of the app's `/media/icons/…`. |
| `AVATARS_PUBLIC_BASE_URL` | *(empty)* | ○ | Same for avatars. |

Limits (compiled in): file records 50 MB, icons and avatars 2 MB.

## Accounts and sign-in

| Variable | Default | Req | Description |
|---|---|---|---|
| `MVAULT_ADMIN_EMAIL` | `admin@mvault.local` | ○ | E-mail of the administrator. Created at start if missing. **Set this to your existing admin address when upgrading from 0.3.x.** |
| `MVAULT_ADMIN_PASSWORD` | – | ◐ | Password for the first administrator; required on first start of the slim image (the all-in-one image generates one). Ignored once the admin exists. |
| `MVAULT_LOGIN_MAX_ATTEMPTS` | `5` | ○ | Failed sign-ins per e-mail within the window before sign-in is blocked (HTTP 429). The per-address limit is 4× this value. |
| `MVAULT_LOGIN_WINDOW_SECONDS` | `900` | ○ | Length of the throttling window. |
| `MVAULT_TRUST_PROXY` | `true` | ○ | Use the rightmost `X-Forwarded-For` entry (appended by your proxy) as the client address for throttling. Set `false` if mVault is reachable without a proxy. |

## Container and process options

Used by the Docker images (`docker/entrypoint.sh` and the s6 services).

| Variable | Default | Applies to | Description |
|---|---|---|---|
| `PORT` | `8000` | both | gunicorn listen port. (The image `HEALTHCHECK` still probes 8000.) |
| `GUNICORN_WORKERS` | `3` | both | Worker processes. |
| `GUNICORN_TIMEOUT` | `120` | both | Worker timeout in seconds; keep your proxy timeout at least this high. |
| `MVAULT_PROVISION_BUCKETS` | `false` | slim; all-in-one with external storage | Create missing buckets at start (needs `s3:CreateBucket`). Embedded MinIO always provisions. |
| `MVAULT_STORAGE` | `embedded` | all-in-one | Set `disabled` to run without any object storage. |
| `MVAULT_AUTO_GENERATE_SECRETS` | `false` | all-in-one | Allow generating the encryption key/salt even with an external database. |
| `MVAULT_ADMIN_MUST_CHANGE` | – | set by the image | `true` forces the first admin to change the password; the all-in-one image sets it when it generated the password. |
| `MVAULT_DB_MODE`, `MVAULT_S3_MODE` | – | set by the image | `embedded`/`external`/`disabled`, derived from your settings. Internal; do not set. |

## Development

| Variable | Description |
|---|---|
| `MVAULT_SEED_PASSWORD` | Password for demo users created by `manage.py seed_local`. |
| `.env.local` | Loaded automatically by `settings.py` (see `.env.local.example`). |

## Management commands

| Command | Purpose |
|---|---|
| `check_config` | Prints version, database and storage reachability, and warnings (no secrets). |
| `provision_storage [--wait N]` | Creates the three buckets if missing. |
| `rotate_encryption_key [--dry-run]` | Re-encrypts all values from `OLD_MVAULT_ENCRYPTION_*` to the current key/salt. |
| `ensure_admin` | Creates the first administrator if missing. |
| `wait_for_db` | Waits up to 120 s for the database. |
| `seed_local` | Demo data for development. |
